# 论文 PDF 整理与文献检索工具

选择一个文件夹，扫描其中的 PDF，将学术论文命名为：

```text
年份-末位作者全名-期刊简称-论文标题.pdf
2024-Bob Jones-Nat. Commun.-A reproducible method for measuring nanoscale material properties.pdf
2017-Bob Jones-arxiv-A reproducible method for measuring nanoscale material properties.pdf
```

文件名只写四位年份，不写月份和日期。作者统一取作者列表中的最后一位；找不到可靠全名时作者栏留空并标为 **需要核对**，可以稍后补全，也可以直接勾选，按 `2024-Nat. Commun.-论文标题.pdf` 重命名，不写占位作者名。

这是本地程序，带中文浏览器界面。已在当前 Mac 中创建独立 `.venv` 环境并安装依赖。

界面顶部可切换 **论文重命名** 和 **文献检索**。更新程序后，先关闭旧启动窗口中的服务，再双击 `启动程序.command` 重新启动。

## 文献检索

1. 切换到 **文献检索**，选择保存全部文献的大文件夹。程序自动包含所有子文件夹中的 PDF（含 `.PDF`），跳过符号链接、程序环境及重命名历史目录。
2. 点击 **建立 / 更新索引**。默认离线识别；可勾选 **联网补全题录与发表时间**，通过 Crossref / arXiv 补全。界面显示进度及复用缓存的数量，PDF 内容和文件名保持不变。随后读取全部页面进行去重核对，默认将确定重复的多余副本移出文献库；取消勾选 **核对后移除确定重复的副本** 可只检查、不移除。
3. 输入开始年份、结束年份、作者、标题中的一个或多个条件，点击 **检索文献**。年份输入四位数字，例如 `2024`，范围包含起止年份。作者匹配完整作者列表中的任一作者；标题、作者均支持不区分大小写的关键词组合。
4. 可按发表时间从新到旧、从旧到新、作者或标题排序，每页 50 条。点击 **打开 PDF**，使用系统默认 PDF 阅读器查看原文。
5. 下次打开会记住上次选择的路径并读取已有索引。新增、修改、移动、重命名或删除文献后，点击 **建立 / 更新索引**：未改变的文件复用缓存，已移走的路径从索引移除。离线索引切换到联网时会重新补全；联网记录可在离线模式复用。

文献列表只显示发表年份。未识别年份的文件显示 **时间未知**，在时间排序中排到末尾，设置年份范围时不参与匹配。时间缺失、非论文、读取失败的 PDF 仍保留在索引中，便于按位置查看；标题无法识别时可用文件名关键词检索。扫描件需要先进行 OCR 才能检索正文中的题录。

索引保存为程序目录下的 `.paper-library.sqlite3`（可能伴有 `-wal`、`-shm` 文件），包含本地路径和识别到的题录，不保存 API Key。使用 Python 自带 SQLite，无需安装数据库。首次索引耗时取决于文件数量、体积和是否联网。

### 全文核对与去重恢复

去重在题录识别完成后执行，读取每个 PDF 的全部页面。文件 SHA-256 完全相同，或全部页面文字及页面图像都一致，才认定为确定重复。页面核对覆盖图表、公式和批注，并额外比较批注内容、表单、书签、附件；签名文件只按字节完全相同去重。优先保留目录较浅、文件名较短的副本。相同 arXiv 编号、DOI，或相同标题作者，只用于标记候选；正文、图表或批注有差异的修订版、预印本和正式发表版会保留。

确定重复的副本移至文献库内的隐藏目录 `.paper-duplicates/批次编号/`，并记录 `manifest.json`，不会永久删除。此目录不参与后续扫描。界面 **全文去重核对** 可查看保留路径、移除路径和核对依据；点击 **恢复上次移除的副本** 可恢复，原路径被占用时不会覆盖。恢复后先取消自动移除，再更新索引，可重新检索恢复的副本。

历史批次也可恢复：

```bash
.venv/bin/python app.py --restore-duplicates "/完整/文献文件夹路径" "批次编号"
```

全文核对或移除期间文件有变化时保留原文件并提示重新索引；无法读取的文件和独立补充材料不参与自动去重。备份目录需要保留，才能恢复已移除的副本。

## 在 Mac 上使用

桌面已创建带自定义图标的 **文献检索.app** 快捷入口。双击即可启动本地后台服务并直接打开 **文献检索** 页面，重复启动会复用已有后台实例。关闭浏览器不会退出后台；需要停止时，双击项目目录中的 **停止文献检索.command**。启动日志位于 `.paperwise-desktop.log`。

桌面入口指向本项目中的应用，请保留项目位置。移动项目后可运行 `.venv/bin/python install_desktop.py` 重建入口（需要 macOS 命令行开发工具）。也可双击 **启动文献检索.command**，直接进入检索。

1. 双击本目录的 **启动程序.command**，浏览器会自动打开。如果 Finder 用编辑器打开它，请右键选择“打开方式 → 终端”。
2. 点击 **选择文件夹**，或粘贴文件夹完整路径。默认包含子文件夹。
3. 点击 **扫描论文**。此时不会修改 PDF 文件名。
4. 查看识别结果和识别依据。作者统一使用末位作者全名，年份仅显示四位数字。末位作者未识别的条目标为待核对，默认不勾选；可以等待核对，也可以保留作者空白并手动勾选重命名。已识别的作者也可以手动清空。期刊和标题仍需补全。识别为非论文的条目不允许编辑、勾选或重命名。
5. 点击 **重命名所选文件**。文件保留在原来的子文件夹中。
6. 需要恢复时点击 **撤销上次重命名**。重新扫描可继续处理。

启动窗口要保持运行，退出时在启动窗口按 `Control+C`。浏览器页面关闭不会自动停止后台程序。默认地址为 `http://127.0.0.1:8765`，端口已被占用时会选择其他可用端口，以启动窗口显示的地址为准。

也可以在本目录的终端中运行：

```bash
./启动程序.command
```

其他系统：Windows 双击 `启动程序.bat`（需要 Python 3.9+）；Linux 或手动安装：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python app.py
```

Windows 激活命令为 `.venv\Scripts\activate`。程序只依赖 PyMuPDF，没有 Node.js、数据库或系统 OCR 的安装要求。

## 识别方式

- **发表年份**：优先使用标题匹配的 Crossref 发表日期（在线发表、纸质发表、published、issued），其次使用 PDF 前两页的明确发表标注。arXiv 使用首次提交年份，不使用后续修订年份。文件名、编辑框、文献列表和重命名 CSV 只显示年份，月份和日期不写入文件名。不使用文件创建、修改时间或 Crossref 数据入库时间代替发表年份。无法确认时用 `时间未知` 作文件名前缀，可手动填写年份；内部索引保留原始日期用于检索。
- **论文类型**：结合摘要、研究章节和参考文献识别学术论文，包含期刊研究论文、学术综述和会议论文。识别为非论文的手册、简历、账单、学位论文、独立补充材料等直接取消重命名资格；AI 判定为非论文时也一样。前端禁用选择和编辑，后端依据最新扫描结果校验，不能通过手动修改字段绕过。类型尚不确定的条目仍需要人工确认。
- **命名作者**：统一取作者列表的最后一位作者全名。通讯作者信息只作为识别依据保留，不会替代未知的末位作者，也不会用于自动命名。
- **末位作者来源**：优先使用标题匹配的 Crossref / arXiv 元数据中的作者顺序，其次使用经过首页原文核对的完整 PDF 作者元数据。PDF 没有作者元数据时，还会尝试读取标题与摘要之间的首页作者区。末位作者无法读出、列表末尾不完整或只有无法展开的缩写时留空，不取前面的作者替代，也不编造姓名。
- **作者可选**：未识别末位作者时显示待核对，作者栏保持空白；期刊和标题齐全即可手动勾选并重命名。可以手动补全或清空作者。全名保留原文空格、连字符及姓氏前缀。
- **arXiv 论文**：支持首页完整或拆行的 arXiv 标记、旋转页边标记、DOI、abs/pdf/html 链接及标题区域的超链接。对于没有水印的作者原稿，标准 arXiv 下载文件名编号会结合全文论文结构核对，或联网与首页标题核对。参考文献中提到 arXiv 不会单独触发。期刊字段固定为 `arxiv`，即使联网匹配到已发表版本的期刊，也按 arXiv 来源命名。
- **其他预印本**：支持 bioRxiv、medRxiv、ChemRxiv、Research Square、SSRN、Preprints.org 和通用 PREPRINT 标注；来源分别使用 `biorxiv`、`medrxiv`、`chemrxiv`、`researchsquare`、`ssrn`、`preprints.org`、`preprint`。缺少期刊和同行评审不再阻止其作为研究论文参与索引和重命名。全文结构也支持首页没有 Abstract 标签、Methods 和 References 位于中间页的作者原稿。
- **标题**：先检查 PDF 自带元数据与首页原文是否一致，再结合首页字号和版面识别标题。保留论文原文标题，不自动翻译。
- **期刊简称**：优先使用 Crossref 提供的 `short-container-title`，其次使用程序内置的常见期刊简称表。不能确认的期刊简称留待手动填写，不生成自造缩写。
- **DOI 核对**：只有元数据标题与本篇首页及已提取标题匹配，才采纳 DOI 结果，避免把引用文献的信息当作本篇论文。

识别为预印本时，以来源代替期刊字段，继续提取原文标题并按相同命名格式处理。没有可靠来源标记的文件仍可手动补全。扫描件、加密 PDF 和损坏文件会显示失败原因；扫描件需要先用其他工具进行 OCR。程序不修改 PDF 内容。

程序读取全部页面中的可提取文本，用于论文类型、题录及通讯标注识别；去重另外核对全文、页面图像及批注等信息。罕见版面仍可能需要人工核对，因此保留预览和修正步骤。

## 联网和可选 AI

默认勾选 **联网核对标题与期刊**：普通论文会向 Crossref 公共接口发送 DOI，或在没有 DOI 时发送推测的标题；arXiv 论文可向 arXiv 公共接口发送本篇 arXiv ID，补全原文标题和有序作者列表。**不向这些书目接口发送 PDF 文件或全文**。取消勾选即可关闭这些联网查询，arXiv 的本地来源识别仍可使用。

不填 API Key 即可使用本地规则和可选的 Crossref / arXiv 查询。若希望 AI 辅助识别复杂版面，可展开配置并启用：

- **API 地址**：兼容 OpenAI Chat Completions 的服务基础地址，例如 `https://api.openai.com/v1`，不要填写到 `/chat/completions`。
- **模型**：填写该服务实际支持的模型 ID，程序不预设模型。
- **API Key**：填写对应服务的密钥；无需认证的本机服务可留空。

启用 AI 会将选取页面的文本片段（每篇最多约 48,000 字符）发送给配置的服务，可能产生服务商费用。API Key 只保留在当前页面与扫描任务的内存中，不写入配置文件、浏览器存储、重命名日志或请求日志。API 地址必须使用 HTTPS，只有本机地址允许 HTTP。程序会验证 AI 返回的原文证据；命名仍使用经验证的有序作者列表中的末位作者，未知则留空。AI 请求失败时保留本地识别结果，AI 明确判定非论文时跳过。

完全离线使用：取消联网核对选项，并保持 AI 关闭。首次安装 PDF 依赖仍需要联网。

## 文件重名、长度和撤销

文件名会移除跨平台不支持的字符，保留中文和 Unicode，并限制为最多 240 个 UTF-8 字节，作者全名最多保留 128 个 UTF-8 字节，期刊简称最多保留 64 个字节，过长标题会按剩余长度截短。已有同名文件时自动追加 ` (2)`、` (3)` 等编号，绝不覆盖。

每次操作会在**所选文件夹**下创建隐藏目录 `.paper-renamer-history`，保存原文件名、目标文件名、文件指纹及执行状态。请保留此目录以便撤销。它不包含 PDF 全文或 API Key。修改过的文件、已被占用的原文件名会阻止相应撤销，避免覆盖或误恢复。

界面中的撤销对应当前会话最后一次成功的批次。关闭程序后，可查看历史目录中的 JSON 文件，以文件名去掉 `.json` 后的批次 ID 执行恢复：

```bash
.venv/bin/python app.py --undo "/完整/PDF文件夹路径" "批次ID"
```

程序不会跟随符号链接，不移动子文件夹，不处理 PDF 以外的文件。安全的无覆盖操作需要文件系统支持硬链接；部分 exFAT/FAT32 移动硬盘不支持，会保留原文件并提示将工作副本放到 APFS/NTFS 等支持的磁盘中整理。

## 开发与验证

```bash
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python app.py --no-browser --port 8765
```

源代码分别位于 `paper_renamer/extract.py`（识别）、`dates.py`（发表时间与时间精度）、`library.py`（本地索引与分页检索）、`metadata.py`、`arxiv.py`（可选外部服务及 arXiv 来源识别）、`rename.py`（重命名和撤销）、`app.py`（本地服务）和 `web/`（界面）。程序只监听本机回环地址，并校验修改请求的来源。

实现参考：[PyMuPDF 文本提取](https://pymupdf.readthedocs.io/en/latest/recipes-text.html)、[Crossref REST API](https://www.crossref.org/documentation/retrieve-metadata/rest-api/)、[arXiv API](https://info.arxiv.org/help/api/index.html)、[OpenAI JSON 输出](https://developers.openai.com/api/docs/guides/structured-outputs)。
